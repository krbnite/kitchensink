# Time-Series Data Augmentation

This is a kitchensink index page for the standalone project repo:

- Local repo: `/Users/kevin/github/CVB/time-series-data-augmentation`
- Expected GitHub repo: `https://github.com/krbnite/time-series-data-augmentation`

The project preserves Kevin Urban's July 2020 work on data augmentation for
sensor time series and human activity recognition, including:

- nudged Box-Cox augmentation ideas
- homotopic and partial-homotopic augmentation ideas
- realistic noise-injection level estimates for time-series windows
- literature and code references for time-series augmentation
- a TensorFlow/Keras HAR setup notebook that was adjacent to planned Neural
  Structured Learning experiments

## Why It Belongs In The Archive

- Time-series augmentation was a planned CVB research/review-paper direction.
- The work is sensor-specific rather than copied over from image augmentation.
- The notes include several original or independently developed ideas with
  timestamps from July 2020.
- The notebooks preserve executed figures that make the ideas easier to inspect.

## Archive Notes

The standalone repo was created by filtering the relevant history from the
broader CVB sensor analytics repository, then adding two snapshot-only notebooks
from a one-commit rescue repo. Transfer-learning and DRCN/domain-adaptation
materials were deliberately left out for later standalone curation.
