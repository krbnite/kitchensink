# Sensor Domain Adaptation And Dataset Similarity

This is a kitchensink index page for the standalone project repo:

- Local repo: `/Users/kevin/github/CVB/sensor-domain-adaptation-and-dataset-similarity`
- Expected GitHub repo:
  `https://github.com/krbnite/sensor-domain-adaptation-and-dataset-similarity`

The project preserves Kevin Urban's 2020 CVB-era exploration of dataset
similarity metrics for wearable-sensor and human-activity-recognition data.

## Why It Belongs In The Archive

- It turns the abstract domain-adaptation question into a concrete project:
  estimate whether one subject, sensor dataset, or domain is close enough to
  another for transfer to be plausible.
- It includes notebooks and helper code around proxy A-distance and related
  dataset-similarity ideas.
- It includes unusually practical notes on how preprocessing choices differ
  between tabular data and time-series windows.
