  `https://github.com/krbnite/time-series-domain-adaptation-notes`

The project preserves Kevin Urban's 2020 CVB-era notes on transfer learning,
domain adaptation, human activity recognition, and sensor/time-series machine
learning.

## Why It Belongs In The Archive

- It captures the literature-review layer behind later sensor-domain work.
- It preserves dated thinking around transfer learning, domain adaptation,
  covariate shift, and cross-domain activity recognition.
- It provides context for the data-augmentation and dataset-similarity projects
  without making those repos carry every surrounding note.
