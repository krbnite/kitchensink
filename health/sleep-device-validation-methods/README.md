# Sleep Device Validation Methods

This is a kitchensink index page for the standalone project repo:

- Local repo: `/Users/kevin/github/sleep-device-validation-methods`
- Expected GitHub repo: `https://github.com/krbnite/sleep-device-validation-methods`

The project preserves Kevin Urban's 2024 TPV Revisited work: a restart of a
sleep-device validation analysis focused on PSG-vs-device agreement,
timestamp-alignment problems, and bounded Dynamic Time Warping (DTW) for
sleep/wake hypnograms.

## Why It Belongs In The Archive

- Clinical/wearable sensor analytics.
- Time-series alignment and agreement metrics.
- Practical validation of consumer sleep devices against PSG.
- Evidence of taking over an overcomplicated inherited analysis and rebuilding
  the core methodology in a clearer package.

## Archive Notes

The standalone repo keeps publishable code/history separate from private local
materials. Raw data, executed notebooks, presentations, and prior-project
context are collated inside the standalone repo under an ignored `_private/`
folder so the project is physically consolidated without pushing sensitive or
bulky files to GitHub.

The Git history has been filtered to foreground Kevin's 2024 rebuild work while
excluding the larger inherited TPV implementation, raw study data, and executed
notebook outputs from public history.
